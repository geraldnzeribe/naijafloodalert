NaijaFloodAlert on any phone

Most smallholder farmers and riverside families use basic phones with little or no data. This demo shows NaijaFloodAlert as a USSD menu: no app, no internet, works on any handset. Choose a language, your state and your LGA, and get today's flood alert, farm advice and season outlook, all built from the same live data as the main map.

Try it

  1. Press Call (the demo code is pre-filled).
  2. Reply with the menu numbers: language → state → LGA → what you want.
  3. 8 shows more, 0 goes back. End hangs up.

Demo only: no real USSD code or SMS is used yet. The menu logic (js/ussd.js) follows the Africa's Talking USSD format, so it can be connected to a real short code without changes.
